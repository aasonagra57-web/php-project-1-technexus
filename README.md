# Technexus — IT Club Notice Board

A web-based notice board project designed to help an IT club share important announcements with students in one place.

## 📌 About the Project

Technexus is a small-scale notice board website where IT club administrators can manage notices and students can view published announcements.

The project aims to make sharing club updates and student information simpler and more organized.

## ✨ Features

- **View Notices:** Students can view notices shared through the website.
- **Manage Notices:** Administrators can add, update, and delete notices.

## 🛠️ Technologies Used

- PHP
- HTML\CSS from themewagon
- phpmyadmin used as database
